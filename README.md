# Tic Tac Toe

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

Live link : https://rehannbuilds.github.io/Tic-Tac-Toe/

## Features

- Two-player gameplay
- Turn indicator
- Win detection
- Restart game

## Technologies Used

- HTML5
- CSS3
- JavaScript
